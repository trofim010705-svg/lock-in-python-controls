# Signal Recovery 7230 · Lock-in Histogram 1.0

Приложение PyQt5 для управления Signal Recovery 7230 по USB и измерения
распределений Magn1 / Phase1. Запуск — **`app.py`**. `gui_app.py` также запускает
то же приложение и содержит существующие органы управления прибором.

## Установка

Рекомендуется Python 3.11/3.12 x64. Команды CMD из папки проекта:

```bat
py -3.11 -m venv venv
venv\Scripts\python.exe -m pip install --upgrade pip
venv\Scripts\python.exe -m pip install -r requirements.txt
venv\Scripts\python.exe app.py
```

В PyCharm выберите интерпретатор `venv\Scripts\python.exe`.
Если зависимости уже установлены, сохраните свою папку `venv`.

Для реального USB нужен тот же VISA-драйвер (например, NI-VISA) и привязка
USB RAW, с которыми работала ваша библиотека `lockin_7230_usb.py`.
Один PyVISA не заменяет системный VISA-драйвер. Приложенная библиотека
сохранена без изменений; ResourceManager создаётся только в рабочем потоке.

Адрес по умолчанию: `USB0::0x0A2D::0x0027::14078415::RAW`.
Другой номер и тайм-аут задаются при запуске:

```bat
venv\Scripts\python.exe app.py --serial 14078415 --timeout 3000
```

`--max-frequency 250000` нужен только для прибора с опцией 7230/99;
стандартное ограничение встроенного генератора — 120 kHz.

Без подключённого прибора / VISA-драйвера:

```bat
venv\Scripts\python.exe app.py --demo
```

В DEMO показания условные, на окне и в метаданных явно указана симуляция.
Деморежим подключается кнопкой «Подключить USB», затем используется обычный Start.

## Работа

1. Подключите локин. До Start текущие значения обновляются на экране,
   файлы измерений не создаются, гистограмма не пополняется.
2. Во вкладке «Управление Lock-in» доступны прежние Main Controls,
   Oscillator, Rear Panel, Equations. Настройки применяются автоматически
   после завершения ввода; справа показано подтверждённое значение прибора.
   Опрос не закрывает раскрытые списки и не затирает незавершённый ввод.
3. В «Измерительный цикл» заполните:
   - **Sig, Bal** — mV, записываются как параметры эксперимента;
   - **Acquisition time** — длительность одного цикла, s;
   - **E field, H field** — значения вместе с нужной единицей, например
     `2.1 kV/cm`, `53.2 mT`; это ручные метаданные;
   - **Delay** — запрошенный период начала единичных измерений, ms;
   - **Additional** — произвольные комментарии;
   - папку для пары выходных файлов.
4. **Start** запускает один цикл. Сначала завершаются предыдущие USB-команды
   и изменения настроек, затем прибор перечитывается для метаданных.
   Отсчёт Acquisition time начинается после подготовки, перед первым измерением.
   Пока цикл идёт, программные настройки локина и параметры цикла заблокированы.
5. Magn1 и Phase1 автоматически добавляются в две гистограммы. Показывается
   число отсчётов в каждом бине, а не плотность вероятности. Все завершённые
   пары входят в обе гистограммы, включая отсчёты с флагом перегрузки.
6. После Acquisition time или **Stop** сохраняются `.dat` и `.txt`.
   Сразу начинается обычный фоновый опрос, если флажок «Опрос» включён.
   Следующий цикл запускается отдельным Start; автоматического повторения нет.
   До следующего Start гистограммы последнего цикла остаются видимыми.

Sig/Bal не используются для дополнительного пересчёта Magn1 в угол.
Сохраняются физические значения, возвращённые локином: **V** при входе
напряжения, **A** в токовом режиме; Phase1 — **градусы** в исходном диапазоне
прибора. Развёртки и приведения к 0–360° при записи нет.
Настройка REFP1 (опорная фаза) и измерение Phase1 (PHA1) — разные величины;
REFP1 и REFP2, когда второй демодулятор включён, входят в снимок настроек.

## Время и USB

Обращения к прибору выполняет один QThread, использующий существующую
библиотеку USB и протокол `write_raw(command + NUL) / read_raw()`.
Никаких параллельных соединений и конкурирующих чтений нет.
Во время цикла обычные фоновые запросы приостановлены; текущие Magn1/Phase1
на экране обновляются из тех же измеренных пар.

Для Single reference используются `MAG.` и `PHA.`; для Dual harmonic /
Dual reference — `MAG1.` и `PHA1.` (§6.6.05 и §6.6.14 руководства 7230).
Режим прибора автоматически не переключается. Данные второго демодулятора
не записываются, но его включённые настройки сохраняются.

Magn1 и Phase1 читаются **последовательно**, это не аппаратно одновременный
снимок двух величин. Время начала и окончания каждой пары записывается в TXT.
Delay задаёт период «начало — начало». Если USB медленнее этого периода,
пропущенные интервалы пропускаются, очередь догоняющих запросов не создаётся.
В TXT сохранены запрошенный период и фактические min/mean/max.
Уменьшение Delay не гарантирует такой же частоты независимых физических
измерений: она также зависит от USB и постоянной времени самого локина.

Длительность контролируется монотонными часами в рабочем потоке, независимо
от системных часов и перерисовки графиков. Начатая до границы времени пара
дочитывается целиком, поэтому завершение может немного выйти за Acquisition
time. Stop также ждёт завершения текущего USB-запроса (до VISA timeout).
Гистограммы перерисовываются не чаще пяти раз в секунду, без пропуска данных.

## Файлы

Одинаковое уникальное имя, например:

```text
lockin_20261102_123000_123456.dat
lockin_20261102_123000_123456.txt
```

DAT: два столбца с заголовком, табуляция, десятичная точка, точность 17 цифр:

```text
Magn1_V    Phase1_deg
0.0010001  -31.25
```

При токовом режиме заголовок первого столбца `Magn1_A`.
Формат подходит для импорта ASCII в Origin; первая строка — названия колонок.
Каждая строка — одна полностью считанная пара; незавершённая пара при ошибке
USB не добавляется. При остановке до первого отсчёта DAT содержит заголовок.

TXT содержит:

- все введённые параметры с единицами, Additional и признак DEMO;
- времена начала/окончания UTC, причину завершения и число строк;
- режим, вход V/A, прошивку, USB-адрес, используемые команды измерения;
- текущие настройки всех доступных разделов локина: sensitivity, TC,
  источники опоры, REFP, частоты, offsets, фильтры, генератор, модуляцию,
  заднюю панель, цифровой порт и уравнения;
- реальные ответы команд, значения кодов и читаемые обозначения настроек;
- предупреждения о неподдерживаемых командах — такие значения не выдумываются;
- фактический период, число перегрузок и потерь захвата;
- таблицу `Index | Read_start_s | Read_end_s | Status | Overload` для каждого
  отсчёта, с тем же порядком строк, что в DAT.

JSON-блок настроек расположен между `CONFIGURATION AND RESULT` и
`SAMPLE TIMING / STATUS`; весь файл читается как обычный UTF-8 текст.
Снимок настроек читается перед циклом. Имена ранее записанных файлов не
перезаписываются; при совпадении добавляется `_001`, `_002` и т. д.

## Ошибки и сохранность

- Stop сохраняет уже полученные точки, включая неполный по времени цикл.
- При ошибке/потере USB накопленные полные пары также сохраняются с причиной
  `usb_error` и текстом ошибки, связь закрывается. Для нового цикла подключитесь
  снова. Ошибка во время подготовки отмечается как `preparation_error`.
- Если файл записать не удалось, данные остаются в памяти. Новый Start
  заблокирован, доступна кнопка повторного сохранения в другую папку.
  До успешного сохранения обычное закрытие окна не удаляет накопленные данные.
- При закрытии окна во время записи сначала выполняются Stop и сохранение,
  затем закрывается USB-поток. Принудительное завершение процесса или потеря
  питания не сохраняют данные, которые ещё находятся только в памяти.
- После успешного сохранения массивы отсчётов освобождаются из памяти;
  остаются гистограммы и информация о файлах.
- За один цикл допускается до 1 000 000 пар. При достижении лимита цикл
  завершается и сохраняется с причиной `memory_limit`.

## Код и проверка

- `app.py` — запуск;
- `gui_app.py`, `gui_widgets.py` — прежние органы управления и USB worker;
- `lockin_7230_usb.py` — ваша библиотека без изменений;
- `measurement/worker.py`, `measurement/engine.py` — сеанс, опрос и снимок;
- `measurement/data.py` — параметры, DAT/TXT и безопасное сохранение;
- `measurement/histogram.py`, `measurement/ui.py` — гистограммы и интерфейс;
- `tests/` — тесты протокола, UI, цикла, Stop, сбоя USB и повторного сохранения.

```bat
venv\Scripts\python.exe -m unittest discover -s tests -v
```

Сборка EXE выполняется на Windows:

```bat
venv\Scripts\python.exe -m pip install pyinstaller
venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onedir --windowed --name LockinHistogram --exclude-module PyQt6 --exclude-module PySide6 --exclude-module PySide2 app.py
```

На другой компьютер переносится вся папка `dist\LockinHistogram`.
Системный VISA-драйвер для реального USB устанавливается отдельно.
