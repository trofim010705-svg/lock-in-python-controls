Magnetic Lab 1.2 — Lock-in 7230 + GEN60-40 + NI USB-6363

Распакуйте всю папку MagneticLab и запускайте MagneticLab.exe.
Папка _internal должна оставаться рядом с EXE. Python отдельно не нужен.
Системные драйверы NI-VISA, NI-DAQmx и CP210x устанавливаются отдельно.
Уже работающие драйверы от отдельных программ можно использовать здесь.

Настройки локина находятся на второй вкладке. Выберите COM магнита и имя
устройства NI из NI MAX (например Dev1). NI читает ai3 Differential.
Калибровка поля: B[mT] = k[mT/mV] * U[mV] + b[mT].
Значения k=1, b=0 являются начальными; задайте калибровку своего датчика.

При подключении выход магнита не включается. Начальный ток устанавливается
по Start измерения. При том же знаке лишнего обнуления нет. При смене знака
ток обнуляется с проверкой, затем переключается реле.
Новая кнопка «Сменить полярность и подать ток» после обнуления и переключения
подаёт величину из поля ручного тока. Режим прохода принимает −10…+10 A.

Все исходники и полная инструкция находятся в папке Source/README_RU.md.
Симулятор: запустите EXE с параметром --demo.
Проверки сборки используют симулятор и не заменяют пробный проход на приборах.

Версия 1.1: отдельная кнопка сохранения значений по умолчанию вверху первой вкладки.
Правая кнопка на числовых полях не открывает меню.
Выбор после успешного измерения: обнулить ток либо оставить конечную уставку.
При Stop, ошибке и закрытии программы ток обнуляется.

Версия 1.2: Start/Stop перенесены в левую панель, журнал — в отдельную вкладку.
При обрыве связи проход ждёт переподключения, затем повторяет незавершённую точку.
Частичные попытки сохраняются в incomplete/, история соединений — в experiment.txt.
После переподключения магнита сначала проверяется источник, затем ток обнуляется
с подтверждением, восстанавливаются полярность и уставка. Stop отменяет ожидание.
Если связи нет, обнуление не может быть подтверждено программой.
