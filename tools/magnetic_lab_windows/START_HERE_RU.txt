Magnetic Lab 1.4 — Lock-in 7230 + GEN60-40 + NI USB-6363

Распакуйте весь архив и запускайте MagneticLab.exe. Оставьте папку _internal рядом.
Python отдельно не нужен. Системные NI-VISA, NI-DAQmx и CP210x нужны, как прежде.

Версия 1.4 сохраняет уставки и выход при Stop, ошибке, подключении,
переподключении и закрытии. Обрывы NI/Lock-in не обнуляют магнит.
+5 A -> переподключение -> проход +3..+10 A выполняется без промежуточного нуля.
После успешного измерения по умолчанию остаётся конечная уставка.
Старое сохранённое предпочтение «обнулить» из 1.1/1.2 не переносится автоматически.

Новая кнопка «Гистерезис · старт → стоп → старт» запускает прямой и обратный
ход одним измерением. Используются поля начального/конечного тока и количества
шагов. N шагов в каждую сторону дают 2N+1 точек, точка разворота измеряется один раз.
Пример: −5 → 0 → +5 → 0 → −5 A при двух шагах на ветвь.
На развороте ток не обнуляется. При смене знака — прежняя проверка нуля и реле.
Действие после завершения применяется только в конце всей петли. По умолчанию
после возврата остаётся стартовый ток; можно явно выбрать обнуление после успеха.
Прямой/обратный ход показаны разными цветами и символами. Всё сохраняется в одну
папку; summary.dat содержит коды ветвей (1 — прямой, 2 — обратный), experiment.txt
и parameters.txt каждой точки — sweep_branch. Картинки PNG/PDF содержат обе ветви.

При неизвестной полярности ненулевого источника укажите текущий знак и нажмите
«Подтвердить знак без переключения». Это не меняет ток/выход/реле.
Последний известный знак сохраняется для того же источника внутри программы;
протокол не позволяет считать фактическое положение контактов реле.

Обнуление остаётся по отдельной кнопке, для заданной нулевой точки,
при реальной смене знака или выбранной явно опции «обнулить после успеха».
Реле переключается только после проверки нулевого тока и выключенного выхода.

Подключите тот же COM источника, Lock-in и Dev1/ai3 Differential.
Калибровка: B[mT] = k[mT/mV] * U[mV] + b[mT]. Начальные k=1, b=0 — замените на свои.
Start/Stop находятся слева. Подробный журнал — на отдельной вкладке.
При обрыве связь восстанавливается автоматически; прерванная точка измеряется заново,
предыдущая попытка сохраняется отдельно в incomplete/.

Полная инструкция: Source/README_RU.md. Запуск симулятора: MagneticLab.exe --demo.
Сборка проверена в симуляторе; физические приборы при сборке не подключены.
