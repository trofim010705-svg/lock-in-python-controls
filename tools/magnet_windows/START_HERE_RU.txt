Magnet Command Tester 1.4 — Windows x64

1. Распакуйте ВЕСЬ архив, например в C:\Lab\MagnetCommandTester.
2. Запустите MagnetCommandTester.exe.
3. Оставьте папку _internal рядом с EXE: в ней находятся Qt и другие библиотеки.

Python, PyCharm, LabVIEW и NI-VISA для этой утилиты не нужны.
Драйвер CP210x для вашего USB-устройства по-прежнему должен быть установлен.

Для подключения ПК → коммутационный блок → GEN IN выберите:
«Подключение реле» → «Коммутационный блок и GEN · общий COM».
Адрес, скорость, программные пределы тока и напряжения задаются в окне.
При запуске и подключении выход не включается и уставки не меняются.
После H/X требуется ручная проверка связи, контакты программой не подтверждаются.
Программа не устраняет аппаратные неисправности USB или питания блока.

Файл build_info.json содержит версии библиотек, контрольные суммы и результаты
проверки запуска готового EXE на Windows (в обычном и кириллическом пути).
Это проверка интерфейса и симулятора, не физического оборудования.

Сборка не имеет цифровой подписи. Сертификат издателя в неё не включён.
Исходники приложения и сборки находятся в Source; сведения о лицензиях
компонентов — в Licenses и метаданных соответствующих пакетов.

Полное руководство приложения находится в Source\README_RU.md.
